# S10 — TraceMaker ortamı

12 Ekim 2026 · **Tamamlanmadı: Windows yeniden başlatması ve Ubuntu gerekiyor.**

Kullanıcı WSL2 + Ubuntu kurulumunu onayladı; PCBench indirmesini reddetti (yalnız KiCad demoları).
Yükseltilmiş `wsl.exe --install -d Ubuntu --no-launch` Windows Subsystem for Linux ve
VirtualMachinePlatform bileşenlerini etkinleştirdi. Kurulumun ölçülen son mesajı, değişikliklerin sistem
yeniden başlatıldığında etkinleşeceğini belirtiyor. [Yerel kurulum kaydı](../../.pcbai-state/wsl-elevated.txt).

Henüz ölçülmeyenler: Ubuntu'nun listelenmesi; cpu-only derleme süresi/disk/GCC/commit; beş demoda rota ve
yerleşim; iki koşunun hash eşitliği; Linux süreç ağacının timeout sonrası kapanması; `/mnt/c` performansı.
Bu alanlar Windows sahte motor testlerinden veya projenin README iddialarından doldurulmaz.

Yazılım tarafında WSL dağıtım/yol izin listesi, sabit sürücü dönüşümü, açık `env HOME/XDG` izolasyonu,
GNU `timeout --kill-after` ve Windows süreç sınırı hazır. Canlı WSL doğrulaması hâlâ gerekir.

Yeniden başlatma sonrası kurulumun tamamlanması ve şu yapılandırma gerekir:

```powershell
wsl --install -d Ubuntu
wsl -l -q
$env:PCBAI_TRACEMAKER = 'wsl:Ubuntu:/<cpu-only-derleme>/src/app/tracemaker'
$env:PCBAI_TRACEMAKER_PLACE = 'wsl:Ubuntu:/<cpu-only-derleme>/src/place/tracemaker-place'
python -m pcbai doctor
python scripts/bench_engines.py --engines tracemaker freerouting --repeat 2
```

Derleme, projenin [resmi cpu-only yönergesini](https://github.com/DingoOz/TraceMaker#quick-start) izler;
çalıştırılan kaynak commit'i S10 yayın ölçümünde sabitlenmelidir. K5 varsayılan motor kararı açık kalır.
