# S4 — Freerouting DSN/SES hattı

12 Ekim 2026 · **Bağdaştırıcı uygulandı; motorun demo kalite kabulü açık.**

`pcbai.pcb.engines` KiCad Python'unu ayrı süreçte kullanır: DSN dışa aktarımı → yapılandırılmış
Freerouting → SES içe aktarımı. KiCad'in normalize ettiği önce/sonra dosyalarında yabancı değişiklik
denetlenir; yalnız izinli rota farkları orijinal dosya baytlarına aktarılır. Dökümler kopyada yeniden
doldurulur; korunan başlıklar ve net biçimi değiştirilmez.

Native Windows 2.5.0 CLI, ecc83'ta `ComponentOutline` için GraalVM `SerializationConstructorAccessor`
hatası verdi. Süreç sonuç üretmeden kaldı; zaman aşımında süreç ağacı sonlandırıldı. Ölçüm (yerel kayıt `.pcbai-state/s4-debug.json`).
JAR yedeği ayrı Temurin JRE ile çalışıyor; bu yedek kurulum ve programlar ürün paketine dahil değil.

Gerçek küçük rota düzeneğinde önizleme → gerçek önce/sonra SVG → uygulama → checkpoint'ten bayt eşit
geri yükleme testi geçti. Bu düzenek bir kullanıcı kartı veya fiziksel kart değildir. Gerçek ecc83 kopyasında
bağlantıların tamamlanmasına rağmen yeni DRC hataları oluştuğunda uygulama engelleniyor.

Beş demo × iki koşu kayıtları yerel JSON (yerel kayıt `.pcbai-state/s4-current.json`) ve
tablo (yerel kayıt `.pcbai-state/s4-current.md`) içindedir. Geliştirme koşuları `docs/spikes/*-result.json`
yayın kanıtlarına yazmaz. Bu rapor motor seçimi veya üretim kabulü değildir.

Tekrar koşu (kullanıcı ayarlarını/kartlarını değiştirmez):

```powershell
$env:PCBAI_FREEROUTING = '<resmi freerouting-2.5.0.jar dosyası>'
$env:PCBAI_JAVA = '<Java 25 java.exe dosyası>'
python scripts/bench_engines.py --engines freerouting --repeat 2 --timeout 60 --output .pcbai-state/s4-current.json
python -m unittest tests.test_engines_integration -v
```

Freerouting deterministik sayılmıyor. Rastgele üretilen rota UUID'leri nedeniyle aynı geometrinin dosya
SHA-256'sı da farklı olabilir; hash eşitliği ölçülmeden determinizm ilan edilmez. TraceMaker ile karşılaştırma
S10 ortamı hazır olduğunda yapılabilir.
